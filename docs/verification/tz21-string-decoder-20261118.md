# BLEGO TZ21 — Декодер строк

## Архитектура
- Основание: BLEGO TZ20 (`codex/blego-tz20-order-text-fixtures-20261118`).
- Отдельная навигация Tools → «Декодер строк» без изменения маршрутов / поведения существующих разделов.
- Выделенный чистый модуль `shared/string-decoder.mjs` с `decodeString(input, format)`, без внешних зависимостей и IPC.
- Форматы: Base64, Base64 URL-safe, URL percent encoding, Hex, автоопределение; ограничение вложенности — 3 уровня.
- Поддержка вложенных Base64(JSON) фрагментов в составных строках через проверку сбалансированного JSON, без предположений о назначении полей и без исполнения содержимого.
- Результат JSON форматируется; обычный текст остаётся без изменения перевода строк.
- Ограничение ввода: 2 МиБ; результат: 4 МиБ; не более 8 найденных встроенных JSON-фрагментов.
- Strict UTF-8, некорректные байты/разделители отклоняются с объяснением.
- Данные живут только в памяти окна и не логируются, не пишутся в архив, не передаются по сети и не отправляются в телеметрию. Отправка в буфер обмена только по нажатию.
- Экранирование HTML — существующий `esc()` в интерфейсе.
- Дизайн: штатные кнопки, панели и переменные CSS; мобильная компоновка в одну колонку.

## Ручная приёмка
1. Меню Tools → «Декодер строк».
2. Выбрать Base64 и вставить `eyJvayI6dHJ1ZX0=`, нажать «Декодировать»: JSON с `"ok": true`.
3. Выбрать «Автоопределение» и вставить `example.test:WyJzdHJpbmciXQ==`: результат — JSON массив.
4. Выбрать URL-encoding: `%D0%A2%D0%B5%D1%81%D1%82+URL` → `Тест URL`.
5. Выбрать Hex: `48 65 6c 6c 6f` → `Hello`.
6. Ошибка: `SGVsbG8$$` в режиме Base64 → понятное сообщение.
7. «Копировать результат» копирует только декодированный текст; «Очистить» удаляет ввод и вывод.
8. Проверить узкое окно: панели в одну колонку, текст не выходит за границы.
9. Вернуться к классификатору и MetaPainter: поведение не изменилось.

Все тестовые строки искусственные. Исходный пример пользователя, пароли и Cookie в репозиторий не включены. PR остаётся черновиком до завершения всех проверок; релиз не публикуется автоматически.
