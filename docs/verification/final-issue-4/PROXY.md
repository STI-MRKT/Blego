# Proxy stage

Official references retrieved 2026-11-13: https://proxycheck.io/api/ and https://proxycheck.io/resources/proxycheck-openapi.yaml. Stable v3 release 2026-06-24. Actual response field is `detections.risk` (0–100); `detections.confidence` is a distinct detection-confidence value. Issue wording “risk_score” refers to the risk metric, not a literal response key. No-key allowance 100/day per requesting IP, free registered key 1000/day. The documented private key mechanism is a query parameter over HTTPS; no request URL, key, raw exception or response message is returned/logged. Key uses the existing main-process safeStorage vault; plaintext fallback is refused.

Local Check makes three HTTPS echo attempts (64 KiB max each, 10 s each) and one TCP connection timing to the selected proxy. Both SOCKS5 and SOCKS5h resolve destination names remotely; only the proxy endpoint is resolved and pinned locally. IP is taken only from successful HTTPS echo through the route. Local/service endpoint resolution is blocked/pinned. Total deadline 45 s; user cancellation throws CANCELLED. Full check explicitly adds a bounded 3 MB download through the same agent. Failed samples remain null.

Quality: at least three attempts and two successful HTTPS timings. `round(100 * successes/N * (0.7 + 0.2*max(0,1-meanRTT/1000) + 0.1*max(0,1-meanAbsoluteAdjacentRTTDifference/200)))`. This fixed operational index is not reputation or a calibrated probability. Speed and TCP are shown separately and never affect Trust.

Trust: `100 − detections.risk`, only for a successful exact-IP provider result and numeric [0,100] risk. Provider lookup is explicit opt-in and travels independently of the entered proxy, with only the verified exit IP and optional owner key. Cache is memory-only, 128 entries maximum: anonymous 1 minute, other results 10 minutes, shortened by future delisting time. An expired cache entry is never fallback success. Provider database `last_updated` is shown separately from fetch/expiry time; it is not the response freshness clock. 401/403/429, malformed responses, mismatch and deadlines preserve local results with unknown Trust.

Controlled tests use actual loopback HTTP CONNECT, TLS CONNECT and SOCKS5 servers with a temporary test CA (never production TLS bypass). Local resolver override exists only in backend dependency injection, inaccessible from IPC. Auth/no-auth, wrong credentials, status errors, SOCKS5/SOCKS5h remote DNS, bounded route download, local-address blocking and secret-free results are covered.

Real external API: native Node fetch without cloud egress configuration failed (PROVIDER_UNAVAILABLE). With `NODE_USE_ENV_PROXY=1`, actual no-key v3 query to public control address 1.1.1.1 succeeded: risk 33, confidence 100, Trust 67. See `proxycheck-live.json`. This verifies the API contract, not a user's proxy. No external owner proxy credentials were supplied; those checks remain BLOCKED. Signing is outside scope.

Stage checks: `npm run verify` PASS (lint; 61 unit, 77 integration); `BLEGO_HEADLESS=1 npm run test:ui` PASS (9 GUI). Final provider-nullability adjustment rechecked with focused proxy/network suites (18 tests) and lint. No tests disabled. Original graphical CSS/resources unchanged.
