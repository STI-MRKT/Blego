# UX5 Photos/date/GEO

The original photo grid/figures/stats/meter are restored. Existing authorized preview tokens produce bounded 300×260 PNG thumbnails using the already bundled Sharp library; originals/metadata exports are unchanged. The main screen exposes selection, date, GPS, Preview changes and Save copies. Camera/text fields, presets, groups/reference copying, reports and file diagnostics remain available in disclosures. Each visible date, coordinate, filename, author/title field, new input and before/after value can be copied independently through the existing clipboard.

New date operation fields are additive: `scope: ['exif','xmp']` selects supported representations; `value.offsetMode` is keep/set/remove. New UI defaults to keep each file's existing timezone, with no OS/current-time/GPS/camera insertion. Legacy presets without these fields retain previous semantics and show their explicit set/remove offset choice. EXIF and XMP offsets are resolved independently from each source. Empty explicit Set offset and empty scope reject. Conflicting duplicate offsets require an explicit choice. Date preview lists each selected representation separately; unselected date fields and unrelated dates remain unchanged.

The existing metadata writer, plans, frozen source hashes, group queue, SQLite, presets, exclusive export and recovery are reused. `date-policy.cjs` supplies only date argument/preview/readback logic to that writer. Verification checks all selected namespace copies and preserves unselected date representations. Export still checks original hash, encoded image content, decoded pixels, orientation, ICC and alpha; outputs are separate copies.
