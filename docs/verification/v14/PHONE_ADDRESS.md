# Generator: национальный телефон и порядок адреса

Реализация: `0a5ee16`; повторная общая регрессия: кандидат `96b81f414490cebd573ab1294895fd0b53c454fc`.

- Отображение и сохранённый профиль содержат полный международный номер.
- Только соседняя кнопка телефона использует код страны сохранённого профиля, удаляет международный префикс и разделители. Изменение селектора страны после генерации не меняет правило для показанной карточки.
- Национальные цифры остаются строкой: ведущие нули не теряются, дополнительный местный префикс не добавляется.
- «Номер скопирован» показывается после подтверждённого native clipboard write/readback. Несоответствующий код/неизвестная страна не превращаются в ложный успех.
- `Copy full set`, модель/история/архив, порядок семипольного экспорта классификатора не менялись.
- Визуальный порядок адресных полей: `address → city → postalCode`; отдельные кнопки сохранены для всех 8 стран × 3 категории.

Проверки: `tests/unit/generator-phone-address.test.cjs`, `tests/ui/generator-phone-address.test.cjs`. Actual Electron GUI проверяет 8 стран, 1280/360 px, отдельные address/city/postalCode copies, exact fullset и неизменную сохранённую карточку после операций/перезапуска.
