# Дополнение владельца: объём приёмки Photos

Указание в чате: «не не, 1000 это много, достаточно 20».

Применено к обсуждавшемуся обязательному нагрузочному GUI-прогону Photos: для текущей приёмки достаточно пакета из20фотографий. Проверки сохраняют вложенные папки, JPEG/PNG/WebP, дату/GEO, предпросмотр, экспорт и повторное чтение, оригиналы, отмену и отзывчивость.

Обязательные batch-наборы:1/10/20; отдельный high-resolution набор3форматов. Установленный GUI проверяет20отдельныхфайлов и20файлов вложенной папки. Для сравнения1.3/1.4 используется один актуальный harness и одинаковый размер20.

Интерпретация доведена до владельца: это снижение обязательного объёма приёмки, не новый запрет загружать больше20. Уже реализованные ограничения1000файлов/10ГиБ и существующие быстрые регрессионные тесты не удаляются. Большие QA-наборы доступны только как дополнительный явно выбранный stress-run. Запущенный до уточнения1000-file Mac-прогон завершается безопасно; его результаты сохраняются как дополнительное историческое свидетельство, не обязательство владельца проверять1000фото.
