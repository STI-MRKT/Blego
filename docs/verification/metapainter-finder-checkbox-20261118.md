# BLEGO — MetaPainter: галочка по умолчанию и задержка Finder

Дата: 2026-11-18.

- Опция подтверждения смены производителя / модели камеры с MakerNotes по умолчанию выбрана. Пользователь может снять галочку. Предупреждение о несовместимости MakerNotes сохранено.
- Пояснение после сохранения добавляет информацию о задержке обновления Finder / Spotlight. EXIF заполняется непосредственно при экспорте, повторное чтение выполняется до публикации. Finder / Spotlight индексируют сведения позже и отображают не все EXIF/XMP/IPTC теги.
- Выделенные на изображении подписи Check.fb.tools «Подробности», «Повторить эту цель» и фраза о проверке не встречаются в коде Checker текущей ветки.
- Проверка на настоящем macOS: ExifTool и ImageIO должны сразу читать Manufacturer, Model, DateTimeOriginal из файла с `_meta_` в имени. Оригинал остаётся неизменённым.
- Не выполнять глобальный `mdutil -E`: переиндексация всей системы избыточна и не гарантирует мгновенное обновление Finder.
- Тесты: `tests/unit/metapainter-export-info.test.cjs`, `tests/ui/metapainter-export-info.test.cjs`, общий набор Linux и macOS.
- Изменения хранятся в изолированной ветке. Слияние и публикация релиза — отдельно.
