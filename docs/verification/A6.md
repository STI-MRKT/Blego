# A6 — selected feeds, persistent per-source cache

RSS/Atom parsed with pinned XML parser; DTD/entities rejected, HTML rendered
as plain text, Unicode/single-quoted links supported, unknown publication dates
remain null. HTTP status, redirects (3), streaming bytes (2 MiB), timeout (10s),
concurrency (4) and cache size (500/source) bounded. Successful source data
persists in SQLite; failures retain stale data and independent timestamps.
Timer runs only in the open app with enabled selected sources (15/30/60/180m).
Disabling cancels in-flight work. UI receives snapshots while keeping filters.

Legacy feeds moved to resources/news/examples.json, explicitly examples only;
none enabled by default and no final journal list invented. New News navigation
uses existing style. Credentials/content from other modules are never sent.
