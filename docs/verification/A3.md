headers and extra CSV cells. Diagnostics include physical CSV line ranges or
JSON object indices. Supports BOM, UTF8/UTF16LE/UTF16BE/Windows1251; assumptions
are visible. Invalid encoding/quotes/JSON are explicit errors. 50 MiB is checked
before reading a browser File and again before a worker starts. Parsing runs in
a worker with cancellation and bounded retained operations. Main owns immutable
source bytes and operation state; renderer receives 50-record pages.

explicit test-only service dependency; no renderer route enables it. Preview
and source copying do not create archives or fake history entries.
