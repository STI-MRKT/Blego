## Design / approaches
Reuse Friends service canonicalUrl to expose a transient copyUrl on list results, without mutating stored rows. Shared small pure helper filters all rows and deduplicates these canonical URLs; UI and copy action consume the same selection. This avoids a second URL validator and avoids a new IPC endpoint. Alternative renderer-only normalization would duplicate and drift from existing validation; new backend clipboard API is unnecessary because existing copyText validates size and readback.
Selection uses cryptographic random integers with rejection of modulo bias and Fisher–Yates; rejection sampling excludes the previous successful set when n>7. Bound repeat attempts and report an error rather than spin indefinitely if RNG fails. No persisted history.
News values travel through escaped attributes in the existing delegated action handler into copyText; no new global listeners. Optional clipboard error-message parameter affects only Friends; existing callers/defaults unchanged. Existing components first; local styles only if actual narrow-layout check needs them.
