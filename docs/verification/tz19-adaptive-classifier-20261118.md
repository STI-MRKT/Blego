# BLEGO TZ19 — адаптивный классификатор и память подтверждённых схем

## Задача
Не изменять успешно распознаваемые TXT/CSV/TSV/JSON, а определять дополнительные поля только в неоднозначных строках и только на основе локально подтверждённых структур.

## Алгоритм
1. Старые правила, заголовки, явное назначение и ручное отображение имеют приоритет.
2. Если в записи остались неопределённые поля, сопоставить её с локальными подтверждёнными схемами по длине и типизированным признакам. Требуется минимум два независимых типизированных поля, хотя бы одно сильное (ID, email, cookie, User-Agent или профиль URL).
3. Поддержать отсутствие до двух необязательных полей: Cookie, User-Agent, backupEmail. Не применять перенос схемы при противоречии типам, конфликте ID или неоднозначном совпадении.
4. Применять схему отдельно к каждой записи. Отмечать `CONFIRMED_LAYOUT_APPLIED` для контроля.
5. Не угадывать назначение двух неподписанных строк без подтверждённой структуры.

## Запоминание
В «Настроить поля» пользователь назначает порядок колонок или поля одной записи, устанавливает «Запомнить подтверждённую структуру» и нажимает «Применить соответствие».

На устройстве сохраняются только канонические названия ролей полей и признаки типов; не сохраняются пароли, Cookie, токены, логины, email, Facebook ID, их хеши, исходные строки и содержимое импортируемых файлов. Максимум 32 шаблона. Есть явное действие «Очистить схемы».

Запоминание не включается автоматически и не использует сеть или машинное обучение. Шаблоны локальны для конкретного профиля приложения.

## Проверки
- Применение двух схем к разным строкам одного TXT;
- отсутствие Cookie без смещения столбцов;
- отказ от неоднозначных и недостаточно подтверждённых совпадений;
- сохранение исходной работающей размеченной структуры;
- обучение по подтверждённому порядку колонок и по ручному назначению одной записи;
- повторный запуск сервиса и очистка памяти схем;
- отсутствие реальных значений в SQLite;
- регрессионные проверки старых файлов и элементов News, Checker, MetaPainter.

Тестовые данные полностью синтетические. Реальные личные TXT/пароли/токены не собираются.
