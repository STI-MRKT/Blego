# MetaPainter — экспорт и проверка метаданных в macOS Finder

Дата: 2026-11-18. Ветка из TZ17; исходные фотографии никогда не меняются.

## Проверяемая проблема

1. `Save copies` создаёт новый файл вида `<name>_meta_<timestamp>__<id>.jpg/png/webp` в выбранной пользователем папке; отсутствие явного результата в простом интерфейсе приводило к проверке свойств старого файла.
2. Ручной ввод Make, Model и других строковых значений оставлял действие `inherit`, поэтому экспорт мог не менять теги.
3. Finder «Создан/Изменён» показывает даты файловой системы, а не EXIF DateTimeOriginal. Finder «Подробнее» не является полным просмотрщиком тегов.

## Критерии

- Список итоговых копий показывается после сохранения и содержит реальные имена готовых файлов.
- Ручное заполнение Make/Model выбирает действие Set; явные изменения видны в результатах.
- Экспортированный JPG содержит корректные EXIF Make, Model, DateTimeOriginal; ExifTool читает теги после публикации, а встроенный macOS ImageIO подтверждает те же значения независимо.
- Исходный JPG остаётся побайтово неизменённым.
- Linux: 32 целевых, 231 модульный, 149 интеграционных, 14 GUI — PASS на `f3c238c6`. Итоговые проверки на новом SHA отдельно обязательны.
- Native macOS ARM64: нативный ExifTool, запуск установленного приложения, ImageIO-проверка, DMG и контрольные суммы — PASS перед выдачей.
- PNG/WebP: метаданные проверяются ExifTool; появление каждого тега в Finder зависит от формата и поддержки macOS, не обещается.
- Публикация релиза и слияние PR не выполняются без решения владельца.
