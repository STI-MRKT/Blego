BLEGO 1.4.5 TZ14 — FP/BIO, Friends, Archive, Settings, Generator pools/phones
Тестовая QA-сборка macOS ARM64 (Apple Silicon), не официальный релиз.

1. Распакуйте install ZIP.
2. Выполните shasum -a 256 -c SHA256SUMS. При несовпадении не запускайте DMG.
3. Перенесите BLEGO.app из DMG в Applications, сохраните существующие локальные данные.
4. Проверьте FP/BIO на широкой и узкой ширине: отступ вкладок, компактные поля,
   отсутствие выбора университета/школы, отсутствие списка истории BIO в интерфейсе,
   сохранение и отдельное копирование содержимого карточек.
5. Friends: отдельные кнопки «Скопировать 7» и «Скопировать все» над карточками,
   «Подробнее» открывает и закрывает дополнительные сведения.
6. Archive: поиск работает после Enter, фильтры/счётчик удалены, открытие,
   экспорт, копирование и удаление данных работают по-прежнему.
7. Settings: расширенная панель не показана, повторы конечных необязательных
   значений разрешены автоматически, идентификаторы контактов остаются уникальны.
8. Crypto: ФП получают криптотематические названия в стиле Tech.
   Tech и ранее сохранённые карточки не изменены.
9. Телефон: отображение и копирование XXX-XXX-XXXX; исходное E164 значение
   по-прежнему хранится в базе и используется механизмом уникальности.
10. Словари: добавлены синтетические сочетания имён, улиц, адресов, BIO,
    статусов, тематик, должностей. Официальные названия учебных заведений
    и проверенные пары «город — индекс» не расширялись без достоверных источников.
11. News и Classifier: функции предыдущей проверенной версии сохраняются.
    Facebook Checker не менялся.

Условия: тестовые данные синтетические. Проверка на пользовательских файлах
остаётся отдельным этапом. Приложение не подписано Developer ID и не
нотариализовано Apple. Не публиковать реальные секреты, пароли, cookie и 2FA
в GitHub или QA-материалах. Ничего не сливается без разрешения владельца.
