# BLEGO TZ18 — переменный порядок полей, без догадок о паролях

- Дополнительные имена заголовков TXT/CSV: `Fb_ID` и метки из пользовательских схем (Proxy, Status, Verified, Followers и пр.).
- Формат с заголовком разбирается независимо от положения колонки Пароль.
- Неизвестные названия колонок распознаются как заголовки, но не становятся ложными полями `birthDate`, `password` и т. д.
- При отсутствии строки заголовков есть новое поле «Порядок колонок без заголовков»: вставить, например, `Логин|Пароль|Fb_ID|Имя|Фамилия|Дата рождения`, нажать «Применить соответствие».
- Несовпадающая ширина записи не даёт сдвинуть значение в чужое поле: `LAYOUT_WIDTH_MISMATCH`.
- Ручные и ранее известные точные назначения остаются приоритетными.
- Регрессия на 50 заданных вариантах структуры; значения тестов исключительно синтетические.
- Предыдущие исправления MetaPainter, Finder/Spotlight и FB Checker включены в ветку.

Критерии: Linux и macOS ARM64 CI PASS, ImageIO EXIF PASS, сохранность originals. Без подписи/нотариализации macOS; PR остаётся черновиком.
