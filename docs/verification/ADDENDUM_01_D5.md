# D5 — verified image copies (2026-11-12)

Implemented export in the existing image service. Main owns destination tokens and rechecks folder identity. Source SHA-256 must match the plan before writing and before publication. Edits run on an exclusive temporary copy, never the original. Completion requires ExifTool read-back, known duplicate-tag checks, encoded-content hash and decoded RGBA/orientation/color/alpha equality. File fsync precedes exclusive hard-link publication (existing files cannot be overwritten); Linux directory fsync follows. On filesystems without hard-link support export fails safely. JSON/TXT reports are explicitly saved, omit before/after values and full paths, and do not overwrite existing files.

At most two jobs run; cancel stops queued/active exports and retains completed copies. Owned temporary directories are registered in existing SQLite and removed after success/failure or on recovery with matching owner marker. No parallel database or generic filesystem IPC. Config files and shell execution remain disabled. Unknown/private metadata may remain; privacy preset is not an anonymity guarantee. Detected signed provenance remains read-only.

Actual profile tests: 4 passed, covering real JPEG/PNG/WebP writes, Unicode values/filenames, leading hyphen and shell-looking filename, negative GPS/altitude, explicit/unknown timezone, known EXIF/XMP/IPTC copies, privacy removal, source change, no-change plan, verification mismatch, injected ENOSPC/EACCES/engine failure, cancellation and recovery ownership. Original SHA, encoded image content and decoded image invariants verified. Expanded GUI selected a directory, exported PNG and independently reread the changed Unicode title.

`npm run verify`: 33 unit + 49 integration passed; lint/format passed. `BLEGO_HEADLESS=1 npm run test:ui`: 1 expanded workflow passed. `node scripts/check-metadata-batch.cjs`: 100/100 completed in 45.161 s; sampled peak RSS 83 MiB for parent and direct engine children. These were 12×8 synthetic RGBA PNGs; this is NOT a worst-case 40 MP/512 MiB capacity measurement. Windows/macOS native exports, full-size stress, physical power loss and real disk exhaustion remain untested. Fault injections do not claim those environments.
