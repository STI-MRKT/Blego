# BLEGO TZ17 — адаптивный классификатор

База: черновик BLEGO TZ15/TZ16; только исправления классификатора. Локальные архивы, другие разделы и исторические значения не мигрируются.

## Принятая семантика
- Обработка перестановок подписанных полей, повторяющихся подписей Email, вертикальной табуляции, записей с двумя почтами и без Cookie.
- Два неподписанных адреса без явных ролей автоматически назначаются, если есть подтверждённая привязка к одной записи (полный UID либо согласованные независимые признаки). При слабой привязке значения остаются для ручного назначения.
- Пароль почты с уникальным структурным признаком может находиться перед email при строгих дополнительных признаках. Два произвольных неподписанных пароля не угадываются.
- Заглавные информационные заголовки не назначаются неподписанным ФИО. Подписанные ФИО и даты учитываются как признаки.
- Неопределённые пароли показываются как «Не определён»; кнопки копирования пустых значений отключены; исходный текст сохраняется.
