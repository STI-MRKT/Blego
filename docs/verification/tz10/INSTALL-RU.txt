BLEGO 1.4.2 QA — ТЗ №10, macOS ARM64

Этот установщик содержит массовое копирование Friends и две кнопки копирования в карточках News. Это отдельный QA-кандидат, не официальный релиз.

1. Распакуйте BLEGO-1.4.2-TZ10-macOS-ARM64-install.zip в отдельную папку.
2. Проверьте DMG командой shasum -a 256 -c SHA256SUMS из этой папки.
   Ожидается BLEGO-1.4.2-arm64.dmg: OK. При несовпадении не открывайте образ.
3. Откройте DMG и перенесите BLEGO.app в Applications. Не удаляйте существующие локальные данные BLEGO.
4. Запустите BLEGO из Applications, вне репозитория и образа.

Friends:
- Выберите GEO, площадку и поиск. «Скопировать 7» выбирает семь разных ссылок из всего подходящего списка, включая другие страницы.
- При менее семи уникальных ссылках эта кнопка недоступна. «Скопировать все» копирует имеющиеся ссылки.
- URL разделены переносами строк, без имён и нумерации. Повторная подборка по возможности отличается от предыдущей; ссылки берутся локально.
- При отсутствии ссылок обе кнопки недоступны. При отказе clipboard или превышении лимита 10 МиБ приложение сообщает ошибку и не выдаёт обрезанный список за успех.

News:
- В каждой карточке есть «Скопировать заголовок» и «Скопировать ссылку».
- Вставьте содержимое в текстовый редактор: должно присутствовать только выбранное значение целиком.
- Кнопки копирования не открывают браузер. Нажатие на заголовок открывает статью.
- Проверьте пять тематик, обновление, сохранённый кэш и узкое окно.

ФП/BIO, Classifier, Photos/GEO, Facebook Checker, Network и форматы данных в рамках ТЗ №10 не менялись.

Подпись и установка:
Developer ID и нотариальное заверение Apple отсутствуют. Успешный запуск на QA Mac ARM64 не гарантирует запуск загруженной копии на любом устройстве. Gatekeeper может запретить открытие. Не отключайте системную защиту и не удаляйте quarantine автоматическими командами. Если macOS блокирует запуск, остановите установку и сообщите владельцу текст ошибки; для обычного распространения требуется Developer ID и нотариализация.

Финальная пользовательская приёмка остаётся за владельцем. PR не слит, официальный релиз не опубликован.
