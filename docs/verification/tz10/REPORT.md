## Реализация

**Friends.** Рядом с фильтрами, вне заголовка страницы, добавлены «Скопировать 7» и «Скопировать все». GEO, площадка и поиск применяются ко всему списку до пагинации. Существующий `canonicalUrl` формирует временное поле `copyUrl`; сохранённые записи не меняются. Некорректные URL исключаются, нормализованные дубли удаляются. Формат буфера — только URL, разделённые LF.

Семь ссылок выбираются перемешиванием Fisher–Yates с `crypto.getRandomValues` и rejection sampling без modulo bias. При пуле больше семи предыдущий успешный набор полностью не повторяется. История остаётся в памяти сеанса. При менее семи ссылках первая кнопка недоступна, при нуле — обе. Успех сообщается после подтверждения существующим clipboard IPC и обратным чтением. Старые карточки, отдельное копирование, импорт, открытие, фильтры и пагинация сохранены.

**News.** В каждой карточке ровно две кнопки: полный заголовок и неизменённый URL существующей модели. Копирование не открывает статью; нажатие на заголовок по-прежнему открывает её. RSS/Atom-парсер больше не обрезает заголовок на 300 символах. Существующие визуальное сокращение CSS и ограничение ответа RSS в 2 МиБ сохранены. Даты, источники и авторы не получили кнопок копирования; общей верхней кнопки нет.

Добавлены только три локальные строки CSS для переноса новых действий и компактных отступов. Используются прежние кнопки, иконки и оформление. Защищённые визуальные ресурсы не изменены.

**Границы изменений.** Classifier, ФП/BIO, Photos/GEO, Facebook Checker, Network, SQLite и форматы архивов не менялись. В `main.js` добавлены только ветви существующего делегированного обработчика и синхронизация доступности действий Friends. `clipboard.js` получил необязательное сообщение ошибки; прежние лимиты и readback сохранены. Новых сетевых запросов при копировании нет.

## Ограничения

- Developer ID и нотариальное заверение Apple отсутствуют. Запуск на QA Mac не гарантирует прохождение Gatekeeper на каждом пользовательском устройстве. Защита не отключается.
- У старого кэша News заголовок мог быть обрезан предыдущей версией. Утраченный суффикс нельзя восстановить локально; следующая успешная загрузка сохранит полный заголовок.
- Отложенное замечание о дополнительных race-тестах описано выше.
- Прежние ограничения неизменённых модулей, включая исторический непрошедший стресс-тест 1000 фотографий, не переобъявлены PASS. В ТЗ10 их код не менялся.
- Финальная пользовательская приёмка остаётся за владельцем. PR не слит, официальный релиз не опубликован.

## Принятые решения

1. Продолжить по подробному ТЗ без повторного согласования; использовать существующее изолированное worktree и новую ветку. Риск — только организация ветки, данные не удалялись.
2. Повторно использовать canonicalUrl через временное copyUrl, не создавать новый валидатор или IPC. Риск — унаследованные ограничения нормализации; совместимость и неизменность хранения проверены.
3. Ограничить повторную случайную выборку 32 попытками, сохранив равномерность. При неисправном RNG — честная ошибка вместо бесконечного ожидания; с исправным RNG вероятность исчерпания пренебрежимо мала.
4. ТЗ10 заменяет прежний полный запрет копирования News: тесты теперь требуют только две карточные кнопки и продолжают запрещать header/metadata copy. Риск случайного возврата лишних действий покрыт новыми assertions.
5. Нативная QA отдельно от ревью кода — обязательный этап до утверждения установщика. Иначе был бы риск непроверенной поставки.
6. Неизменённые модули проверяются общей регрессией и контролем границ изменений, без нового глубокого аудита. Остаточный риск — прежние дефекты вне ТЗ10.
7. Прежние правила нормализации Friends и News сохраняются. Возможные унаследованные ограничения не заменены новой неоговорённой политикой.
