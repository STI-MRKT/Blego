BLEGO: фактические исходные экраны

1280×900, dark, Linux x64. Original — единственный визуальный эталон. Остальные — текущее состояние, не утверждённый дизайн. Нового интерфейса здесь ещё нет. Сеть заблокирована для снимков; данные синтетические, error/empty states настоящие для этого режима. В оригинале News внутри Generator; отдельных News/Settings страниц нет.
