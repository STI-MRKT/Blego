# BLEGO — план внедрения дополнения № 1 (v1.1)

> Для исполнителя: применять `executing-plans` или `subagent-driven-development`, если доступны; отсутствие навыка не меняет требования. Выполнять задачи с воспроизводящими тестами и отдельными проверками. Не запускать вторую независимую реализацию рядом с работающей.

**Цель:** расширить генерацию, диагностировать профили Facebook без ложных вердиктов, добавить локальные метаданные изображений и единое копирование.  
**Архитектура:** существующее Electron-приложение, общий IPC/SQLite/реестр, локальные источники и процесс обработки метаданных. Публичная проверка Facebook — изолированный сетевой модуль.  
**Технологии:** текущий JavaScript/Electron и принятые зависимости; локальный ExifTool по умолчанию. Не менять стек.  
**Спецификация:** `docs/specs/BLEGO_LOCAL_V1_ADDENDUM_01.md`; неизменённые требования `docs/specs/BLEGO_LOCAL_V1_TZ.md` также обязательны.

## Общие ограничения

Нет общего сервера/логина/админки; обязательны телефон/email и страна × model/tech/crypto. Правила предметной классификации отложены. История уникальности не сбрасывается. Оригиналы изображений не меняются. Скрытой сети для файлов нет. Публичная доступность не доказывает отсутствие бана. Данные передаются пользователем, бинарные зависимости не скачиваются при запуске.

Функции и пути ниже — целевые; D0 обязан сопоставить их с уже написанным. Команды `node --test` используются только если действующий проект сохранил этот раннер; при другом принятом раннере указать точные эквиваленты в отчёте до начала. Не заменять работающую систему тестов ради примеров команд.
