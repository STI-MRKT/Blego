## Supported field policy

All three static formats expose title, description, author, copyright, keyword list, comment, capture date with explicit/unknown offset, make, model, software and GPS. The model distinguishes Keep / Set / Remove; empty Set is rejected. Personal identifiers are removal-only. EXIF and XMP copies are examined; JPEG additionally supports IPTC/COM and PNG text fields. Original Orientation, color profiles and encoded image content are protected and not editable. APNG/animated WebP, unknown formats, mismatched extensions and invalid structures are rejected. Detected C2PA/JUMBF provenance is read-only. This is not a complete cryptographic signature detector. Unknown/private blocks remain reported limitations, never an anonymity guarantee.

D4 implements read and preview only; D5 records actual write/read-back evidence separately.
