1. Распакуйте установочный ZIP в отдельную папку.
2. Запустите: shasum -a 256 -c SHA256SUMS
   Для BLEGO-1.4.5-arm64.dmg ожидается OK.
3. Откройте DMG и скопируйте BLEGO.app в Программы (Applications).
4. Сохраните существующие данные BLEGO; не удаляйте рабочую папку.
